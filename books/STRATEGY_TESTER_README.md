## How to use
1. TradingView → Pine Editor → Paste → Save
2. Add to **OANDA:XAUUSD** 1-minute chart
3. Open **Strategy Tester** panel (bottom)
4. Check List of Trades / Overview / Performance

## Notes
- Same BUY/SELL logic as the indicator map
- Orders fill on **bar close** (tester-safe)
- Default: 50% at TP1, rest at TP2 + stop
- Settings → **Strategy Tester** group to turn partial TP / equity sizing on/off
- Keep Beginner mode ON; trade clock is New York

This is for study/backtest. Not financial advice.
